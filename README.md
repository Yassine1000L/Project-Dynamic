# FindInBrussels
Dit project hoort bij het vak "Dynamic Web". De bestanden die in dit project terug te vinden zijn, zijn de volgende: een html-pagina, een css-pagina en een js-pagina
Het onderwerp van de website is het weergeven van publieke streetarts, die in Brussel gevestigd zijn.

# Functionaliteiten
- Het zoeken van een streetart in Brussel.
- Het zoeken van de auteur van een streetart.
- Het weergeven van alle streetarts op de webpagina.
- Het sorteren van alle streetarts op naam: aflabatisch en omgekeerd alfabetisch.
- Het filtreren van alle streetarts op basis van volgende kenmerken:
  - Postcode
  - 


# Sterk Aangeraden Materiaal
- Visual Studio Code
- Extensies op Visual Studio Code:
    - HTML CSS Support
    - Live Server
